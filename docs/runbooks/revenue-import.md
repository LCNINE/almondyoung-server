# 채널 통합 전 매출 자료

판매/통계 → 판매 현황 → 기간별 → 매출 자료에서 연도를 선택한다. 통계 조회 권한으로 엑셀과 반영 이력을 조회하고, 통계 설정 권한으로 월별 자료를 등록한다. 관리자 기본 권한과 마스터가 지원된다. 원본은 기존 아카이브·파일 접근 권한을 그대로 적용한다.

1. 채널에서 원본을 내려받아 팀 스페이스의 루트 문서 `매출 자료`에 비공개 파일로 보관한다. 조회일·계정·기간과 보완 여부를 파일명에 명시한다. 이 문서는 하나만 유지한다. 통계 페이지에 해당 문서의 첨부 다운로드가 표시된다.
2. 통계 페이지에서 최신 취합 양식을 받는다. 채널 원본을 그대로 가져오는 기능은 아니다. 채널·계정·월·매출기준·매출액·출처를 작성한다. 매출액은 원 단위 정수이고, 미수집 월은 행을 만들지 않는다. 확인된 0원은 숫자 0으로 기록한다.
3. 원본확보·월별대조·중복확인·입금대조에 `확인` 또는 `미확인`을 입력한다. 확인으로 표시하려면 대조메모에 근거와 남은 차이를 적는다. 원본 확보만으로 다른 항목을 확인 처리하지 않는다. 기존 6열 양식을 다시 올리면 대조 상태는 미확인으로 초기화된다.
4. 연도별로 불러와 교체 전후 금액을 확인하고 저장한다. 같은 채널·계정·월·기준은 교체되며 계정명·기준 변경은 신규 항목이다. 재수입 시 명칭을 유지한다. 미리보기 이후 다른 사용자가 수정한 자료는 저장을 거부하므로 파일을 다시 불러와 비교한다. 네트워크 오류 뒤 동일 요청을 재시도해도 이력은 중복 저장하지 않는다. 금액·출처 변경 후 확인 상태를 유지하려면 새로운 대조 근거를 적는다. 동시 저장은 서버에서 직렬화하며 이전·새 값과 인증된 반영자를 한 트랜잭션으로 보관한다. 저장 결과는 월별 그래프·표·엑셀과 메인·모든 통계 탭의 통합 매출 목표에 반영된다.
5. 엑셀과 필요한 원본 묶음을 내려받아 검토한다. 최근 반영 이력은 조회 연도에 해당하는 최근 50회이며 기능 적용 전 이력은 복원하지 않는다. 원본 묶음은 연도 필터와 별개이므로 파일명을 확인한다.

카페24 `운영 순매출`은 운영 참고 기준이다. 다른 채널의 신고자료·구매확정·결제완료와 합친 회사 매출은 잠정값이며 신고액으로 간주하지 않는다. 수기 목표 누적액과 이관 주문·채널 원장의 중복, 정산·입금 차이를 확인하기 전 회사 전체 확정 매출로 표시하지 않는다. 대조 상태는 입력자의 근거 기록이며 자동 검증이나 신고 승인이 아니다.

실제 자료·금액·계정·인증정보는 공개 저장소에 보관하지 않는다.

원장은 조회 시작 시 마지막 ID를 경계로 이어 읽는다. 조회 도중 기존 주문 정정이 반영될 수 있으므로 결산 시점의 고정 원장을 의미하지 않는다.

## 회사 전체 매출과 목표

메인과 모든 통계 탭은 같은 회사 전체 매출 화면을 사용한다. 기본 선택은 전체이며 자사몰·스마트스토어·쿠팡을 선택하면 해당 채널의 연간 매출과 누적 그래프를 조회한다. 카페24는 이전 자사몰로 묶고 쿠팡 계정들은 쿠팡으로 합친다. 전화 주문과 자동 수집 기타 채널은 금액이 있을 때 별도 선택할 수 있다. 전체 달성률은 회사 전체 잠정 매출 ÷ 연간 목표이며, 개별 채널에서는 같은 회사 목표에 대한 기여율로 표시한다. 월별 자료는 월말 누적과 진행 중인 달의 등록액으로 표시하고 일별 실적에 배분하지 않는다.

근거 미확인 수기 누적액은 합산에서 제외한다. 과거 설정은 삭제하지 않고 상세 설명과 엑셀에 보관하되 별도 목표 달성률로 노출하지 않는다. 누락과 서로 다른 매출·환불 기준이 남아 회사 전체 확정 매출이나 신고액은 아니다. 환불 조회 실패 시 합계·달성률·그래프·엑셀을 제공하지 않는다. 전체 채널의 일별 근거가 없는 동안 자사몰 속도를 회사 연말 예측·달성 확률·이익으로 표시하지 않는다.

카페24 원본 확보가 확인된 결제완료·신고자료·운영 순매출 중 일별 집계 시작월보다 앞선 완전한 월을 수기 누적액 대신 반영한다. 시작월은 중간 전환일이어도 월 전체를 보류한다. 시작일이 없거나 전환기 이후인 자료는 중복 확인이 있어야 반영한다. 전화 주문은 원본 확보와 중복 확인이 모두 있어야 반영하며 주문 기준 금액은 제외한다. 셀메이트는 자사몰 주문을 중복 입력하는 업무 시스템일 수 있으므로 독립 채널로 합산하지 않는다. 확인 상태는 자동으로 변경하지 않는다.

네이버·쿠팡은 결제완료·구매확정·신고자료를 잠정 반영한다. 동일 채널·계정·월에 기준이 여러 개면 해당 월 전체를 보류한다. 자동 집계에 외부 채널이 나타나면 업로드 합산을 중지한다. 수기액과 원본 소계의 차이는 누락 매출로 간주하지 않는다. 엑셀에 기존 목표·제외 수기액·일별 집계·업로드별 반영 사유를 함께 기록한다.

진행 중인 달은 등록 금액까지 반영하며 선택 기간과 무관한 올해 누적임을 명시한다. 월 합계만으로 일별·상품·고객·이익 지표나 달성 확률을 만들지 않는다. 은행 입금·세금계산서 등 증빙을 매출에 추가 합산하지 않는다. 기존 일별 집계의 취소와 결제 환불 중복 차감 가능성도 대조 대상이다.
