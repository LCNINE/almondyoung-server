GO / NO-GO

교육 시작 전, 네 개의 문을 통과합니다

① 환경

  • 상단에 DEMO · 시연 데이터 표시
  • 관리자 화면과 WMS가 같은 demo 환경
  • 시연 콘솔의 준비 상태를 안내자가 확인

② 계정·창고

  • 역할에 맞는 계정으로 로그인
  • WMS 상단 창고가 데모 국내 물류센터
  • 작업 권한이 없으면 안내자에게 즉시 인계

③ Windows 장비

  • 로그인 후 앱으로 돌아옴
  • HID 스캐너가 문자열 + Enter를 한 번 전송
  • 프린터·라벨 규격은 실물 인수표로 확인

④ 작업 데이터

  • 고정 실습 SKU와 시작 수량 기록
  • 다른 교육생의 동시 작업 여부 확인
  • 발주번호·주문·송장을 작업지에 기록
Windows 설치 산출물의 빌드와 SHA-256 대사는 완료했습니다. 지정 PC 설치·실행, 로그인 callback, 스캐너·프린터는 아직 실물 인수가 필요합니다. 통과 전에는 “장비 검증 완료”로 표시하지 않습니다.

EVIDENCE LABELS

화면과 도식을 구분해서 읽으세요

배포 확인, 저장소 소스, 이후 데이터·실물 확인 항목을 섞지 않고 표시합니다.

● 배포 화면 확인 ● 소스 동작 확인 ● 후속 증거 필요 ● 실물 장비 인수 필요

현재 확인된 것

  • 관리자 demo 로그인과 새 다상품 콘솔 배포
  • 전체 카탈로그 집계·상품 후보 실제 화면
  • 발주 10 → 입고·적치 4+6 acceptance
  • 정상/부족 주문의 모의 출고 완료
  • 인증된 직원 가이드 진입 경로

최종 인수 전 채울 것

  • 지정 Windows PC 설치·로그인 callback
  • 낱개·박스·위치·송장의 실물 스캔 결과
  • 지정 프린터·라벨 용지의 출력·재스캔
  • Windows 앱의 실제 작업 화면 캡처

따라서 “예정” 패널은 업무 개념 설명용이며, 현재 화면의 클릭 절차로 사용하지 않습니다.
