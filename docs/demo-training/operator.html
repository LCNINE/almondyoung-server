CURRENT CONSOLE WORKFLOW

현재 콘솔에서 주문을 만들고 결과를 확인합니다

  1. 실습 상품 검색에 상품명, SKU 또는 바코드를 입력하고 검색을 누릅니다.
  2. 생성 방식에서 무작위 여러 상품 또는 선택한 상품을 고릅니다.
  3. 주문 수 · 주문당 상품 종류 · 품목당 최소/최대 수량을 입력합니다.
  4. 주문 생성을 한 번 누릅니다.
  5. 확인할 주문 요청이 보이면 같은 요청 재확인을 누릅니다.
  6. 생성 이력의 상세에서 주문 링크를 열고 주문과 출고 준비를 확인합니다.
이벤트 접수 완료 ≠ 주문/출고 준비 완료. 화면 문구대로 반영까지 시간이 걸릴 수 있습니다. 상세와 주문 화면을 확인한 뒤 물류에 넘깁니다.
