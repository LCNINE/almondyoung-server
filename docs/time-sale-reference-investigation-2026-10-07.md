# 타임세일 참고 사이트 조사 — 2026-10-07

대상: https://amit.sweetoffer.co.kr/user_admin_interface/

작업 브랜치: `feat/time-sale-admin-styles` (기준 `develop`, `58f347cd6`).

## 요청과 조사 범위

우리 어드민의 타임세일에 타임세일 관리, 메인 매대 스타일, 더보기 매대 스타일,
상품상세 스타일, 환경설정을 구성한다. 사용자가 첨부한 상태 선택·품절모드·모바일/PC
전환을 포함한다. 일반/멤버십 세일가와 멤버십 가격 공개 옵션을 지원한다.

사용자가 열어 둔 Chrome 탭에서 실제 조작으로 조사 중이다. 최초 타임세일은 0개,
서비스는 OFF였다. 검증용 타임세일과 사용자 스타일을 생성하여 등록·편집·저장·활성·중지를 실행했다.
서비스 전체 스위치는 OFF를 유지했다. 기존 머리말/꼬리말/메인 컨테이너의 일시 변경은 원복했다.

**전체 동작 검증은 아직 진행 중이다.** 실제 카탈로그 가격 변경·복원은 테스트 상품 지정 답변 대기 중이며,
자동 가격 갱신과 시작 시 진열/판매 전환은 모두 OFF로 검증했다. SHIFT 회차 자동 전환은 후속 검증에서 확인했다. 쇼핑몰 실화면 연결은 완료로 간주하지 않는다. 아래 초기 조사표의 한계는 후속 검증 기록으로 보완한다.

사용자 지시로 **인앱결제, PV 충전, 결제내역, 과금 관련 설정은 조사·구현 대상에서 제외한다.**
디자인 전체와 성공/실패 토스트, 미저장 변경 확인창도 복제 범위에 포함한다.

### 현재 남은 검증과 승인 대기

- 실카탈로그 가격 변경/종료 복원: 테스트 상품 지정 답변을 기다림. 자동 가격 갱신은 계속 OFF.
- 검증 스타일 No.1791348183 영구 삭제: 삭제 확인창에서 취소했으며 행위 시점 허용 답변 대기.
  복구 기능이 보이지 않아 Computer Use 확인 정책을 적용했다. 초기화도 확인창만 기록.
- 참고 쇼핑몰 실화면의 더보기/페이지 이동: 편집 미리보기의 클릭은 콘텐츠 전환하지 않음.
  서비스 전역 OFF를 유지하고 있으므로 실화면 동작 완료로 표시하지 않는다.
- IP 접근제어/인증/메일전송/실상품 연관 진열변경은 실행하지 않음.
- 경계값과 모든 세부 입력의 변형을 모두 검증한 것은 아니다. 미검증을 구현 완료로 취급하지 않는다.
- 현재 브랜치 변경은 조사 문서/증거뿐이다. 제품 코드 구현은 아직 시작하지 않았다.

증거는 `docs/time-sale-reference-evidence/`의 스크린샷 및 AX/DOM 상태에 저장한다.
패널 전환 직후에는 이전 패널 닫힘 애니메이션 내용이 일부 함께 나타나므로 구현 기준을 추출할 때 구분한다.

### 메인 매대

- 모바일 기본 구성은 제목, 상태 안내, 타이머, 진행바, 캐로셀, 더보기 버튼이었다.
- PC 기본 구성은 제목, 안내, 타이머, 캐로셀, 더보기 버튼이었다.
- 구성요소는 최대 15개 안내가 있으며 캐로셀/상품목록은 하나만 허용한다는 안내가 있다.
- 텍스트 내용은 `{{time_sale_name}}` 등 변수 삽입을 지원한다.
- 버튼에는 내용, 클릭이벤트(주소 이동/더보기 이동), 크기, 글꼴, 색상, 테두리/모서리 설정이 있다.
- 미리보기의 MORE 버튼을 눌렀지만 페이지/팝업 변화는 관찰되지 않았다.
  따라서 실제 쇼핑몰에서의 더보기 클릭 동작을 검증했다고 볼 수 없다.

### 더보기 매대

- 표시 방식은 팝업/주소 방식 안내가 있으며 현재 기본값은 팝업이었다.
- 기본 구성은 제목, 상태 안내, 타이머, 진행바, 상품목록이었다.
- 상품목록 편집기를 열어 가로 2열, 세로 3행 기본값을 확인했다.
- 페이지 설정을 열어 표시 여부, 페이지 윈도우(기본 5개), 글꼴/테두리/모서리,
  일반/현재 페이지 색상을 확인했다. 실제 페이지 이동은 미검증이다.
- 전용 페이지를 사용하려면 별도의 카페24 페이지를 구성해야 한다는 안내가 있다.

### 상품상세 스타일

- 기본 구성은 상태 안내, 타이머, 진행바, 추천상품 제목, 캐로셀이었다.
- 타이머 편집기를 열어 숫자 글꼴/색상/테두리/여백/배경, 그라데이션,
  days/hrs/min/sec 표시, 구분자, 날짜 0일 숨기기, 날짜를 시간으로 변환 옵션을 확인했다.
- 진행바 편집기를 열어 높이, 막대/배경색, 모서리와 상단/내부/하단 메시지를 확인했다.
- 메시지는 상태, 남은 시간/비율, 시작/종료, 현재 상품 가격·할인·재고 등의 변수를 안내한다.
- 캐로셀 편집기를 열어 슬롯 수, 노출 상품수, 이동 그룹, 자동시작, 무한 반복,
  속도/지연, 핀, 화살표, 테두리, 배경, 정렬을 확인했다.
- 상품 진열 패널은 우선순위/랜덤 가져오기 안내를 표시했다.
- 상품 속성 패널은 이미지/방향/크기/간격과 기본·품절·예정·마감 JSX Style을 제공한다.
  마감 기본 Style은 회색조·투명도 0.5·클릭 차단을 사용했다.
- 이미지 엠블럼/레이어, 상품 상단/머리말/꼬리말/하단 패널은 존재를 확인했지만
  모든 내부 필드와 변경 동작은 아직 미검증이다.

### 환경설정

확인한 항목: 고급 서비스 설정, IP 접근 제어(최대 10개), 상품상세 URL 방식,
중복 상품 허용, 할인율 소수점 처리, 상품 이미지 크기(1~1500), 화폐 앞/뒤 단위,
설치 대상 페이지(메인/더보기/상품상세), 메일 수신과 PV 부족 알림.

할인율 메뉴를 실제 열어 반올림·올림·버림 옵션을 확인하고 원래 값 반올림을 유지했다.
중복 상품 허용 시 SHIFT 반복 불가, 중복 기간 간격 10분 초과 안내가 있었다.
외부 서비스의 IP·이메일·서비스 설치 설정은 적용하지 않았다.

## 우리 시스템의 현재 흐름

1. `apps/admin-web/.../time-sale-model.ts`: 일반/멤버십 할인율과 품목별 세일가,
   유효성 검증, 기간/품목 중복 판정, Medusa price list 페이로드 생성.
2. `apps/admin-web/src/lib/services/time-sale.ts`: 두 price list 생성/수정/삭제.
   일반용은 region 규칙, 멤버십용은 customer group 규칙을 사용한다.
3. `apps/medusa/src/utils/time-sale.ts`: 기간이 있는 활성 sale price list를 읽고
   제목과 시작 시각으로 일반/멤버십 리스트를 묶는다. price list에는 metadata가 없다는
   기존 코드 설명이 있다. 비활성 리스트는 현재 어드민 조회에서도 빠진다.
4. `/store/time-sale`은 가격 숫자 없이 세일·상품 ID를 내려준다. 상품은 기존
   `/store/products` 흐름으로 읽어 멤버십 은닉과 가격 계산을 적용한다.
5. 쇼핑몰 홈은 진행 중 세일만 조회하고 상품 최대 100개, 세일별 홈 10개를 표시한다.
   품절은 현재 항상 제외한다. `/time-sale`에서도 같은 wrapper를 사용하므로
   더보기 전용 전체 목록/페이지네이션과 분리할 필요가 있다.
6. `membership-filter.ts`에 `hideMembershipPriceForNonMembers`가 이미 있다.
   이는 비멤버에게 variant metadata의 멤버십 가격을 숨기는 정책이며,
   상품 자체를 숨기는 `isVisibleToMembersOnly` 및 구매 제약과 별개이다.
   어드민 상품 정책 수정 API도 존재한다. PIM→Medusa 동기화 원장을 거쳐야 한다.

## 구현 검토안 — 아직 승인/구현 전

### 권장 구성

어드민 타임세일 안에 **타임세일 / 메인 매대 스타일 / 더보기 매대 스타일 /
상품상세 스타일 / 환경설정** 다섯 메뉴를 둔다. 현재 상품 선택·세일가 편집과
가격 계산을 재사용하고 스타일 저장/미리보기/실제 쇼핑몰 적용을 연결한다.

스타일 화면은 왼쪽 구성요소 목록, 가운데 선택 항목 설정, 오른쪽 실시간 미리보기로
구성한다. 상태·품절·모바일/PC·폭·새로고침은 미리보기 도구이며 실제 판매 설정과
분리한다. 모바일/PC별 스타일, 예정/진행/마감별 안내, 구성요소 추가/삭제/정렬,
머리말/꼬리말, 컨테이너 설정을 지원한다. 이미 설치된 UI·드래그·캐로셀 패키지를 우선 사용한다.

### 가격과 멤버십

- 일반/멤버십 세일가를 직접 입력하거나 각 기준가격에서 할인율로 일괄 적용한다.
- 환경설정에 멤버십 가격 공개 기본 정책을 두고 상품별로 상속/공개/멤버십만 공개를
  선택할 수 있게 한다. 기존 상품 정책과의 영향 범위를 화면에 명시한다.
- `멤버십 가격만 숨김`, `일반 세일가도 멤버십만 적용`, `상품 자체를 회원만 노출`은
  다른 정책이다. 첫 번째를 기본 요구사항으로 해석한다. 두 번째/세 번째를 선택할
  경우 서버 가격 규칙과 상품/구매 정책까지 연결해야 한다.
- 비회원 화면에는 숨긴 숫자 대신 `멤버십 회원에게 가격 공개` 문구를 표시한다.
  API·검색 결과·상품 상세·장바구니 가격과 회원별 캐시에서 누출 여부를 검증한다.
- 할인율 소수점 표시는 반올림/올림/버림을 제공한다. 실제 원화 금액 계산 정책과
  화면 할인율 표시 정책을 구분한다.

### 저장과 적용

- 로컬 저장만 하는 화면으로 끝내지 않는다. 서버에 설정을 저장하고 재진입 시 복원한다.
- 가격 원장은 Medusa pricing을 유지한다. 스타일/진열/반복 설정은 별도 서버 영속 저장이
  필요하다. 기존 CMS/설정 저장 경로를 추가 조사하고 없으면 최소 Medusa 모델을 사용한다.
- 새 설정 없이도 기존 타임세일이 현재 기본 스타일로 동작해야 한다.
- 서버 쓰기 경로에서 중복·기간·가격·권한을 검증하고 두 가격 리스트의 부분 실패를 처리한다.
- 활성/중지는 가격과 진열에 함께 적용하고 중지된 세일도 어드민에서 조회 가능해야 한다.
- 반복은 시작/종료 시각과 실제 pricing 기간을 함께 이동한다. 저장만 되고 실행되지 않는
  반복 스위치는 제공하지 않는다.
- 쇼핑몰 홈, 더보기, 상품상세에서 같은 저장 설정을 사용한다. 더보기에는 전체 상품 조회와
  페이지 이동을 적용해 현재 홈 10개 제한을 해소한다.

### 우리 시스템에 추가로 필요한 항목

1. 서버의 상품/기간 중복 검사: 현재 생성의 클라이언트 검사만으로 동시 저장을 막지 못하고
   수정 경로에는 같은 검사도 없다.
2. 가격 부분 저장 복구: 현재 일반 price list 저장 후 멤버십 저장 실패 시 한쪽만 남을 수 있다.
3. 가격 노출·구매 적용·상품 노출 정책을 각각 명확하게 표시하고 회원 상태별 응답을 검증한다.
4. 종료/중지/가격 변경 시 캐시 무효화: 기존 경계 잡을 재사용하고 설정 변경도 반영한다.
5. 스타일 복제와 변경 취소: 편집 미리보기와 실제 게시 상태를 구분하고 미저장 이동을 경고한다.

카페24 스크립트 설치, 외부 서비스 PV 결제/메일 알림, IP 접근 설정은 우리 자체 쇼핑몰에
그대로 옮길 필요가 없다. 파티션/웹로그ID는 기존 쇼핑몰 진열 위치/분석 구조에 맞게 대응시킨다.
사용자 정의 변수 전체 문법 호환과 임의 CSS/HTML의 복제 범위는 구현 설계에서 확정한다.

### 검증 기준

- 재진입/새로고침 후 세일·스타일·가격 공개 설정 복원.
- 상태 3종 × 모바일/PC × 품절 여부 미리보기와 실제 쇼핑몰 일치.
- 일반/멤버십/비회원의 목록·상세·검색·장바구니·결제 적용 가격 검증.
- 회원 전용 숫자가 비회원 응답/캐시/HTML에 포함되지 않음.
- 기간 경계, 중지/재활성화, 반복 회차, 실패 후 복구 검증.
- 관리자 권한, 서버 입력 검증, 상품 중복, 할인금액 경계값 검증.
- 어드민 타입검사/대상 lint, 기존 타임세일 단위 테스트와 변경된 서버/쇼핑몰 테스트.
- 로컬 브라우저에서 주요 상호작용과 모바일/PC 스크린샷 검증.
