# 상품 등록 매뉴얼

관리자(admin-web)에서 새 상품을 만들어 판매까지 올리는 전체 과정을 안내합니다.

---

## 0. 시작하기 전에

- **권한**: `admin` 또는 `master` 권한이 있어야 상품 관리 화면에 들어갈 수 있습니다. 권한이 없으면 화면이 열리지 않습니다.
- **저장 방식**: 대부분의 항목은 **섹션별로 저장**합니다. 각 카드의 **수정** 버튼을 눌러 편집 창을 열고, 그 안의 **저장** 버튼을 눌러야 반영됩니다. 저장하지 않고 창을 닫으면 변경이 사라집니다.
  - 예외로 아래 항목은 **켜는 즉시 바로 반영**됩니다: 기본 정보의 "운영 노출 정책" 스위치, 품목의 "수동 품절 / 선판매 / 항상 판매" 체크박스.
- **편집은 draft(임시저장) 상태에서만** 가능합니다. 이미 활성(판매중)인 상품을 고치려면 먼저 새 draft를 만들어야 합니다(→ 8장).

### 핵심 개념 한눈에

| 용어              | 뜻                                 |
| --------------- | --------------------------------- |
| **상품(master)**  | 하나의 상품. 여러 개의 "버전"을 가질 수 있습니다.    |
| **버전(version)** | 상품 내용의 한 판본.                      |
| **draft(임시저장)** | 편집 가능한 작업용 버전. 아직 손님에게 노출되지 않습니다. |
| **active(활성)**  | 실제 판매 중인 버전. 상품당 하나만 활성입니다.       |
| **발행(publish)** | draft를 검토 후 활성으로 올리는 것 = "상품 등록". |

## 1. 전체 흐름 요약

1. 왼쪽 메뉴 **상품관리 → 등록** 에서 새 상품 생성
2. 자동으로 열린 **편집 화면(draft)** 에서 순서대로 입력
   - 기본 정보 → 상품 상세설명 → 이미지 → 옵션/품목
3. **가격 관리** 화면에서 가격 룰 설정
4. 편집 화면으로 돌아와 **Version 발행** → 상품이 활성(판매 시작)

## 2. 새 상품 만들기

1. 왼쪽 메뉴에서 **상품관리 → 등록** 을 클릭합니다. (`상품 목록` 화면에는 신규 생성 버튼이 없습니다. 반드시 메뉴의 **등록**으로 들어옵니다.)
2. **새 상품 등록** 화면에서 **[상품 생성하고 편집 페이지로 이동]** 버튼을 클릭합니다.
3. 잠시 후("생성 중...") 새 상품(master)과 첫 draft 버전이 만들어지고, **자동으로 편집 화면으로 이동**합니다.

![](/home/pauseb/.config/marktext/images/2026-07-07-11-19-40-image.png)

## 3. 기본 정보 입력

편집 화면에서 **기본 정보** 카드의 우측 상단 **[수정]** 버튼을 누르면 오른쪽에 **기본 정보 수정** 창이 열립니다.

입력 항목:

- **상품명** (필수) — 비워 두면 저장되지 않습니다.
- **브랜드**
- **SEO 제목 / SEO 설명 / SEO 키워드** — 검색 노출용. 키워드는 쉼표 또는 줄바꿈으로 구분합니다.
- **카테고리** — **[선택]** 버튼을 눌러 카테고리 창에서 지정합니다(아래 참고).
- **판매/노출 스위치**
  - **디지털 상품** — 켜면 배송비가 면제됩니다.
  - **도매 전용** — 도매 고객에게만 노출.
  - **해외직구** — 켜면 주문 시 개인통관고유부호 입력이 필요합니다.
  - **멤버십가 비공개** — 비회원에게는 멤버십 가격 숫자 대신 "멤버십 회원 공개"로 표시.
  - **멤버십 회원 전용 노출** — 비회원 목록/검색/상세에서 상품을 숨김.

입력을 마치면 창 아래 **[저장]** 을 누릅니다. 성공하면 "기본 정보를 저장했습니다." 안내가 뜹니다.

![](/home/pauseb/.config/marktext/images/2026-07-07-11-20-46-image.png)

### 카테고리 선택

1. 기본 정보 수정 창에서 카테고리의 **[선택]** 버튼을 누릅니다.
2. **카테고리 선택** 창에서 검색 후 원하는 카테고리를 체크합니다(여러 개 가능).
3. 대표로 삼을 카테고리 옆의 **대표(★)** 버튼을 눌러 대표 카테고리를 지정합니다.
4. **[적용]** 을 누르면 기본 정보 창에 반영됩니다. (아직 저장 전이므로, 기본 정보 창의 **[저장]** 까지 눌러야 최종 반영됩니다.)

## 4. 상품 상세설명 입력

**상품 상세설명** 카드에서 **Markdown** 으로 상세 내용을 작성합니다.

- 텍스트 영역에 상세설명을 Markdown 형식으로 입력합니다.
- **[이미지]** 버튼으로 본문에 이미지를 삽입할 수 있습니다(커서 위치에 삽입).
- 작성 후 카드의 **[저장]** 버튼을 눌러 반영합니다.
- 아래쪽 **Markdown 미리보기** 에서 실제 표시 모습을 확인할 수 있습니다.

## 5. 이미지 등록

**상품 이미지** 카드의 **[수정]** → **이미지 수정** 창에서 등록합니다.

- **대표 이미지** — **[업로드]**(이미 있으면 **교체**) 버튼으로 지정합니다. **[비우기]** 로 삭제. 대표 이미지는 1장입니다.
- **부가 이미지 (최대 5개)** — **[추가]** 버튼으로 올리고, 각 이미지의 삭제(휴지통) 버튼으로 지웁니다. 6개째부터는 "부가 이미지는 최대 5개까지 가능합니다." 안내가 뜹니다.
- 지원 형식: JPEG / PNG / WebP.
- 이미지를 고르면 즉시 업로드되며, 창의 **[저장]** 을 눌러야 최종 반영됩니다.

## 6. 옵션 & 품목

색상·사이즈처럼 선택지가 있는 상품은 **옵션**을 정의하면 **품목(조합)** 이 자동으로 만들어집니다.

### 6-1. 옵션 정의

1. **옵션** 카드의 **[수정]** → **옵션 수정** 창을 엽니다.
2. **[옵션 그룹 추가]** 로 그룹을 만들고 **옵션 그룹명**(예: 색상)을 입력합니다.
3. 그룹 안에서 **[값 추가]** 로 값(예: 레드, 블루)을 넣습니다. 필요하면 **정렬** 순서를 조정합니다.
4. 사이즈 등 다른 그룹도 같은 방식으로 추가합니다.
5. **[저장]** 을 누릅니다.

> ⚠️ **주의:** 옵션 그룹이나 값을 추가·삭제·변경하면 **품목 조합이 다시 생성**될 수 있습니다. 이미 품목별로 이름·가격을 손봐 둔 경우 옵션 변경에 유의하세요.

> 📸 [스크린샷] "옵션 수정" 창 — 그룹명·값 입력, "옵션 그룹 추가"/"값 추가" 버튼

### 6-2. 품목(Variants) 관리

옵션을 저장하면 **품목 (Variants)** 표에 조합별 품목이 나타납니다(예: 레드/S, 레드/M …).

- 각 행의 **[편집]** → **품목 수정** 창에서 **품목 이름**, **판매 상태**(활성/판매중단), **표시 순서** 를 조정합니다.
- 여러 행을 체크하면 하단에 **[선택 활성] / [선택 판매중단] / [선택 해제]** 일괄 버튼이 나타납니다.

> 옵션이 없는 단일 상품은 품목이 하나만 생성됩니다. 이름·순서만 확인하면 됩니다.

> 📸 [스크린샷] "품목 (Variants)" 표 — 옵션 조합별 행과 편집/일괄 버튼

## 7. 가격 설정

가격은 별도의 **가격 관리** 화면에서 설정합니다.

**들어가는 방법** (둘 중 하나)

- 편집 화면의 **Draft 완성 체크리스트**에서 **가격 정책** 타일 클릭, 또는
- 상품 목록에서 해당 상품 행의 **[가격 관리]** 버튼 클릭.

가격은 **세 가지 계층**으로 위에서부터 차례로 설정합니다. 각 계층에 **[룰 추가]** 로 규칙을 더합니다.

| 계층         | 용도                         |
| ---------- | -------------------------- |
| **기준가**    | 기본 판매가. 보통 첫 룰에 고정가를 넣습니다. |
| **멤버십가**   | 멤버십 회원 대상 가격 조정.           |
| **수량별 가격** | 수량 구간별 가격(최소 수량 기준).       |

각 룰에서 정하는 값:

- **적용 범위** — **전체 / 특정 옵션값 / 지정 옵션조합** 중 선택.
  - **특정 옵션값**·**지정 옵션조합** 을 고르면 바로 아래 **[대상 선택]** 버튼이 나타납니다. 이 버튼을 눌러 **어떤 옵션값/품목에 적용할지 대상을 1개 이상 선택**해야 합니다.
  - ⚠️ 대상을 선택하지 않으면 저장되지 않습니다("적용 대상을 1개 이상 선택해주세요." 안내).
- **연산** — **증감(원) / 비율(배수) / 고정가(원)**.
- **값** — 연산에 쓸 숫자.
- **최소 수량** — 수량별 가격에서만 입력.

> 💡 **팁:** 기준가의 **첫 번째 룰(순서 1)** 은 **적용 범위 "전체" + "고정가"** 로 두는 것이 기본입니다.

설정 후 화면 상단의 **[저장]** 을 누릅니다. 아래쪽 **가격 시뮬레이션** 과 **옵션별 가격 현황** 에서 결과를 미리 확인할 수 있습니다.

> 가격 관리 화면에서는 **발행되지 않습니다.** 가격을 저장한 뒤 편집 화면으로 돌아가 발행합니다.
> 좌측 상단 **← {상품명}** 링크로 편집 화면으로 돌아갈 수 있습니다.

> 📸 [스크린샷] 가격 관리 화면 — 기준가/멤버십가/수량별 가격 3계층과 "룰 추가"

> 📸 [스크린샷] 적용 범위를 "특정 옵션값"으로 두고 "대상 선택" 팝오버에서 옵션값을 체크하는 모습

## 8. 발행하기 (상품 등록)

내용과 가격을 모두 확인했으면 발행합니다.

1. 편집 화면 상단의 **상품 등록** 카드로 이동합니다.
2. **[Version 발행]** 버튼을 클릭합니다.
3. 성공하면 "version이 active로 발행되었습니다." 안내가 뜨고, 상품 목록으로 이동합니다. 이제 상품이 **활성(판매중)** 상태입니다.

> 발행 시 서버 검증에 걸리면 붉은 안내에 사유가 표시됩니다. 사유를 확인해 해당 항목을 수정한 뒤 다시 발행하세요.

> 📸 [스크린샷] "상품 등록" 카드 — "Version 발행" 버튼

---

## 9. 발행 후 다시 수정하려면

이미 활성인 상품은 바로 편집할 수 없습니다. **새 draft** 를 만들어 수정 후 다시 발행합니다.

1. 상품 편집 화면 우측 상단 **[새 draft 생성]** 버튼을 클릭합니다.
2. **새 draft 버전 생성** 창에서 **[생성]** 을 누릅니다.
   - 현재 버전의 **가격 정책을 포함한 매핑 정보가 자동으로 복사**되어 새 draft로 넘어옵니다.
3. 새 draft 편집 화면에서 내용을 수정합니다.
4. 다시 **[Version 발행]** 하면 수정본이 새 활성 버전이 됩니다.

> 📸 [스크린샷] "새 draft 버전 생성" 확인 창

## 10. 참고 화면

- **작성중인 상품** (사이드바 상품관리 → 작성중인 상품, `/mall/my-drafts`) — 내가 만들다 만 임시저장 상품을 이어서 편집합니다.
- **버전 트리** (편집 화면의 **[버전 트리 보기]**) — 상품의 버전들을 트리로 보고, 특정 버전을 열어볼 수 있습니다.
- **상태 배지 의미** — `활성`(판매중) / `판매중단` / `임시저장`(draft) / `보관`.
- **활성 아닌 버전을 볼 때** 상단에 노란 안내 띠가 뜨며, **현재 active 버전 보기** 링크로 이동할 수 있습니다.

> 📸 [스크린샷] 상품 목록 화면 — 열(품번코드·상품명·상태 등)과 상태 배지, "가격 관리" 버튼

## 자주 묻는 점 / 체크리스트

- **저장했는데 반영이 안 돼요** → 편집 창의 **[저장]** 버튼까지 눌렀는지 확인하세요. 창을 그냥 닫으면 저장되지 않습니다.
- **수정 버튼이 안 보여요** → 지금 보고 있는 버전이 draft가 아닙니다. **[새 draft 생성]** 후 편집하세요.
- **가격이 저장이 안 돼요** → 적용 범위가 "특정 옵션값/지정 옵션조합"인 룰에 **대상**을 선택했는지 확인하세요.
- **옵션을 바꿨더니 품목이 초기화됐어요** → 옵션 구조를 바꾸면 품목 조합이 다시 생성됩니다. 옵션을 먼저 확정한 뒤 품목·가격을 손보세요.
