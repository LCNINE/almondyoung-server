# 선적 상자 입고 — 스테이션 실기 체크리스트 (#1239 · #1341)

스펙 §12 «사람 검증». 모의 테스트로 대신하지 않는다 — 실제 Windows 스테이션에서 합성 데이터 한 선적(예: `11월 2차 배편`, 상자 L1~L3 과 범위 줄 하나)을 끝까지 돌린다.

## 준비

- [ ] core → admin-web → warehouse-app 배포 순서가 끝났고 `npm run deploy:preflight -- --stage live` 가 통과했다.
- [ ] **첫 상자 확정 전에 스테이션이 새 앱 버전인지 확인한다**(`UpdatePrompt` 로 갱신). 옛 앱의 입고내역은 선적 입고 한 건부터 안 뜬다.
- [ ] 작업자 계정에 `inventory.stock.read`·`inventory.stock.operate` 가 있다. (operate 가 없는 계정은 F8~F12 가 안 그려지는지도 한 번 본다.)
- [ ] admin-web 에서 합성 선적을 올려 확정했다(상자 L1~L3, 한 줄은 L1~L3 범위 줄, 자유 줄 하나).

## 스테이션 (Windows)

- [ ] 입고 화면 위쪽에 «선적 상자 입고» 링크가 보이고 열린다. 폰에서는 링크가 없거나 «스테이션에서 하는 작업이에요».
- [ ] 대기: 상자 이름(`L1`)을 치고 Enter 하면 상자가 열린다. 같은 이름이 둘 이상이면 고르기가 뜬다.
- [ ] **숫자**: 숫자 입력으로 지금 줄 덮어쓰기, Enter 다음 줄, ↑↓ 이동, Esc 그 칸 되돌림. Backspace 로 한 자리를 지우면 빈칸이 된다(0 아님). 100만 초과는 막힌다.
- [ ] **스캔**: 이 상자 줄의 상품 바코드 → 그 줄에 +입수. 리스트에 없는 바코드 → «리스트에 없던 물건» 줄 + 주의 소리. 등록 안 된 바코드 → 오류음 + «등록되지 않은 바코드예요».
- [ ] **F8 리스트대로**: 단일 상자 줄에서만 켜진다. 범위 줄·리스트에 없던 물건 줄에서는 기능키 바에 안 보인다. 채운 칸에 «리스트대로» 표시. 숫자나 스캔으로 고치면 «센 것»으로 바뀐다.
- [ ] **F9 리스트에 없던 물건**: SKU 검색으로 고르면 줄이 생기고 수량을 친다. 0 으로 만들면 줄이 사라진다.
- [ ] **F10 두 번**: 빈칸이 있으면 «빈칸 N줄» + 오류음 + 커서가 첫 빈칸으로. 빈칸이 없으면 확정 확인이 뜨고 한 번 더 F10 → 확정. 리스트와 다른 줄만 확인 화면에 뜬다. 성공하면 초록 테두리·완료음·«적치 대기로 갔어요».
- [ ] 마지막 상자를 확정하면 «이 선적의 상자를 다 받았어요»가 더해진다.
- [ ] **F11 확정 취소(두 번)**: 방금 확정한 상자(끝 상태)와, 이름으로 다시 찾은 확정된 상자(읽기 전용 화면) 모두 취소된다. 취소 뒤 빈칸에서 다시 시작한다. 선적이 저절로 끝난 뒤에도 당일 취소가 된다. 적치를 시작한 상자나 어제 확정한 상자는 거절된다(앱 문구).
- [ ] **F12 리스트에 없는 상자로 받기**: 이름을 쳐 상자를 더하고 받는다. 저절로 끝난 지 30일 안인 선적에도 된다. 사람이 닫은 선적은 «다시 열기 뒤에 받으세요».
- [ ] **앱 재시작 중 uncertain**: F10 확정 직후 네트워크를 끊어 응답을 잃고 앱을 끈다 → 다시 켜 같은 상자를 열면 수량이 잠기고, 서버 상태를 다시 읽어 확정됐으면 끝으로, 아니면 같은 키로 다시 보낸다. 이중 확정이 없다(재고 1회만 RECEIVE).
- [ ] **두 스테이션 동시 확정**: 같은 상자를 두 곳에서 열고 한쪽이 확정 → 늦은 쪽은 «다른 곳에서 이미 확정했어요» 후 확정된 상자 화면으로.
- [ ] 관리자가 열려 있는 상자의 줄을 고친 뒤 상자를 다시 열면 «N줄 다시 확인» 안내가 뜬다.

## 기존 화면

- [ ] **입고내역**: 선적 입고 줄이 있어도 화면이 뜬다. 줄에 «선적명 · 상자 L7» 이 보이고 줄 단위 취소 버튼이 없다. 스테이션에서는 그 줄에서 상자 화면으로, 폰에서는 «스테이션에서 취소해요».
- [ ] **적치 대기**: 선적 입고로 생긴 회차가 목록에 뜨고 시트가 열려 적치된다.
- [ ] **폰 안내**: 폰에서 `/inbound/boxes` 로 들어가면 «스테이션에서 하는 작업이에요».
