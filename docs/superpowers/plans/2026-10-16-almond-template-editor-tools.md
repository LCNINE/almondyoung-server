# 아몬드템플릿 에디터 도구 보강 — 이어서 할 일

브랜치 `feat/almond-template-editor-tools` (커밋 전, 작업 트리에만 있음).
시작점은 시안 템플릿 디자이너들의 수정 요청이다.

> 질감(Bevel & Emboss), 그림자 위치·색·진하기, 도형 비율 자유 수정(별 끝 늘리기), 펜툴,
> 테두리·선 점선, 테두리 끝 둥글게/각지게, 텍스트 최소 크기 1, 좌우반전,
> 여러 개 선택 시 한 번에 편집, 방향키가 안 먹힘, 개인 글꼴은 어디서 불러오나

코드는 `web/almondyoung-storefront/src/domains/almond-template/` 아래에 있다.

## 끝난 것

- 방향키: 체크박스·select·버튼·슬라이더에 포커스가 남으면 단축키를 통째로 버리던 것을 고쳤다.
  글자를 치는 칸만 키를 가져가고, 슬라이더는 값을 움직이는 키만 가져간다 (`hooks/use-editor-shortcuts.ts`)
- 한글 자판: 글자 단축키를 `event.key` 대신 `event.code` 로 읽는다. 한글 상태에서 `Shift+P` 가 `ㅖ` 로 와서 안 먹던 문제
- 좌우·상하 반전: 더보기에서 꺼내 "순서" 줄 오른쪽으로 올렸다(텍스트·도형·이미지). `Shift+H` / `Shift+V`.
  회전한 요소는 각도도 거울 쪽으로, 여러 개면 묶음 가운데를 축으로 뒤집는다
- 테두리: 실선/파선/점선, 각지게/둥글게 (`strokeDash`, `strokeRound`)
- 그림자: 가로·세로·흐림·진하기·색. 회전·반전해도 화면 기준 방향을 유지한다
- 입체(Bevel): 크기·세기·빛 방향. 조명 필터 대신 흐린 윤곽을 민 차이로 만들어 확대율·인쇄 해상도에 따라 세기가 변하지 않는다.
  rsvg-convert(인쇄)와 크롬 결과가 같음을 확인했다
- 별: 꼭짓점 수(3~20)·뾰족함
- 펜(`P`): 클릭=꺾인 점, 끌기=곡선, 첫 점=닫기, Enter=한 선 끝내기. 다 그려도 펜이 켜져 있고 Esc/✕ 로 끈다.
  펜촉 커서, 닫힘 표시, 동그란 점
- 점 편집: 펜 도형 더블클릭 또는 속성의 "점 편집"(기본 도형은 펜 도형으로 바뀜). 점·핸들 끌기, 점 더블클릭=곡선↔꺾기,
  Alt=핸들 따로, 방향키=점 옮기기, Delete=점 지우기. 끝나면 상자를 곡선에 다시 맞춘다
- 연필(`Shift+P`): 자유곡선 → 떨림 평균 → Douglas–Peucker → 베지어. 보정 슬라이더(0~100),
  방금 그은 선이 골라져 있으면 보정을 바꿀 때 바로 다시 다듬는다
- 그리기 도구 막대: 펜/연필 전환(단축키 표시), 보정, ✕
- 여러 개 선택 패널: 채우기·테두리·선두께·선 모양·글꼴·글자 크기·투명도·효과·반전. 값이 다르면 "혼합"
- 텍스트 최소 크기 1
- 드래그 선택: 네모에 걸치기만 해도 고르던 것을, 네모 안에 다 들어온 것만 고르게 바꿨다
- 다음 선 스타일 이어받기: 펜·연필로 마지막에 그은 선의 색·두께·선 모양·끝 모양·투명도를 다음 선이 물려받는다

검증: `npx vitest run src/domains/almond-template` 전부 통과, `npx tsc --noEmit -p .` 에서 이 도메인 오류 0.
계산 로직은 `lib/path-shape.test.ts` 가 지킨다.
