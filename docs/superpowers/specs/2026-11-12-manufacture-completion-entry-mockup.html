정한 것
  • 권한은 지금 그대로 재고 조정 권한(관리자)만
  • 진입점은 F6 재고 조회 안 하위 탭 제조 완료
  • 재고가 있는 위치가 한 곳이면 자동 선택. 입고기본존도 후보에 넣는다(컷오버 전엔 늘 입고기본존). 가상 구역 꼬리표는 없음
  • 기다리는 출고·예약 변화는 화면에 띄우지 않는다(SKU별 API 없음, 부족 수량을 그대로 넣게 만들 위험). 예약 재시도는 출고 화면에서 검증
  • 오늘 등록한 제조 목록·앱 재고 이력은 두지 않는다. 등록 직후 결과 화면으로 확인하고, 지난 기록은 admin-web 재고 현황 이력에서 본다
