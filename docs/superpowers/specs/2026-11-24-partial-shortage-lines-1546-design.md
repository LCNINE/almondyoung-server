# 부분출고·출고불가 내역에서 모자란 상품을 바로 보이게 (#1546)

## 왜
출고 준비(`/order/waybill-issue`)의 부분출고 내역은 상자의 모든 상품 줄에 같은 회색 `주문 N · 지금 보낼 N · 기다릴 N` 을 찍는다.
무엇이 모자라 부분출고가 됐는지 줄마다 읽어야 안다. 모자란 상품이 한눈에 보여야 한다.

## 목표 / 비목표
- 목표: 부분출고·출고불가 내역의 상품 칸에서 모자란 상품과 모자란 개수가 바로 읽힌다.
- 비목표: 확인 창(`split-confirm-dialog.tsx`) — 이미 기다릴 상품만 상품별로 모아 보여 준다. 사유 칸(`blockedReason`) — 이미 모자란 줄만 «언제·어디서 오는지»를 보여 준다. 서버 응답 변경 없음.
- 반목표: 다 있는 줄에 숫자·안내 글씨를 더 얹는 것(정상 상태는 조용히).

## 방식
고려한 둘:
- **A. 흐리게(선택)** — 다 있는 줄은 이름만 회색으로 남기고 숫자는 뺀다. 상자 구성이 한눈에 보이고 누를 것이 없다.
- B. 접기 — 다 있는 줄을 «다 있는 상품 N개»로 접는다. 표는 짧아지지만 구성을 보려면 눌러야 한다.

사용자가 A 를 골랐다(2026-11-24).

## 정한 것
- 모자란 줄 판정은 `qty > reservedQty`. `stock` 칸은 옛 응답에 없을 수 있어 판정에 쓰지 않는다.
- 모자란 줄: 상품 이름과 수량 줄을 `text-red-600 font-semibold`(이 화면의 다른 경고와 같은 색). 수량 줄은 모자란 개수를 앞에 둔다.
  - 부분출고: `N개 모자람 · 주문 N · 지금 보낼 N`
  - 출고불가: `N개 모자람 · 주문 N · 이 창고 재고 N (다른 주문 몫 N)` — 지금 `shortageLineText` 의 정보 그대로, 순서만 모자람이 앞.
- 다 있는 줄: 이름만 `text-muted-foreground`, 수량 줄 없음.
- 출고불가 갈래는 지금처럼 모자란 줄에 `stock` 이 하나라도 있을 때만 줄 목록을 보이고, 없으면 `itemSummary` 로 둔다(옛 응답 동작 유지).

```
샴푸 500ml                       ← 빨강 굵게
  3개 모자람 · 주문 5 · 지금 보낼 2   ← 빨강
린스 500ml                       ← 회색, 숫자 없음
```

## 빌더 몫
- 모자란 줄을 위로 올릴지(현재 순서 유지가 기본) — 줄이 많아 묻히는 사례가 보이면 그때.
- 판정·문구는 순수 함수로 두고 스펙으로 지킨다. 기존 `bucket-list.spec.tsx` 의 부분출고·출고불가 기대 문구를 새 문구로 고친다.
