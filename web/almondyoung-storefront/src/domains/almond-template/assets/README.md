# 클립아트 출처

`clipart-data.json`의 컬러 SVG는 [Google Noto Emoji](https://github.com/googlefonts/noto-emoji)의 `2D/svg` 파일을 사용합니다. 저작권은 Google에 있으며 Apache License 2.0 조건에 따라 배포합니다. 라이선스 고지는 `noto-emoji-LICENSE`에 있습니다.

와우프레스의 클립아트 그림은 포함하지 않았습니다. 분류와 카드 구성은 편집기 사용 흐름을 참고한 것입니다.

`frame-library.json`의 42개 모양틀 경로는 아몬드영 편집기용으로 새로 작성했습니다. 와우프레스 모양틀 원본 파일을 포함하지 않았습니다.

`almond-holiday/`의 8개 컬러 SVG도 아몬드영 편집기용으로 새로 그렸습니다. `clipart-data.json`에는 이 그림의 데이터 URI와 Noto Emoji가 함께 들어 있습니다.
