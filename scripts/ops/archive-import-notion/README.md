# 노션 export 반입기 (드라이런)

노션에서 내보낸 사내위키를 관리자 아카이브로 옮기기 위한 일회성 도구다.
지금 있는 것은 **드라이런뿐** — 무엇이 몇 건 생기는지만 세고 아무것도 쓰지 않는다.

## 왜 화면이 아니라 스크립트인가

한 번 옮기면 끝나는 일이라 업로드·진행률·재시도가 딸린 화면을 먼저 만들 값이 없다.
이관이 한 번 성공한 뒤에 같은 파서를 재사용해 화면을 붙이는 편이 싸다.

## 실행

```bash
# 1) zip 을 푼다. 셸 unzip 은 쓰지 말 것 — 한글 이름을 깨뜨리고 3개는
#    «File name too long» 으로 실패한다(한글은 UTF-8 에서 3바이트).
python3 scripts/ops/archive-import-notion/extract.py <export.zip> /경로/notion-export

# 2) 드라이런
npx tsx scripts/ops/archive-import-notion/index.ts /경로/notion-export
```

미해결 링크·부모 미상·없는 첨부가 하나라도 있으면 종료코드 1 이다. **0 이 되기 전에는
쓰기로 넘어가지 않는다** — 525페이지가 잘못 들어가면 되돌리는 값이 크다.

## 함정 세 가지 (전부 실제로 밟았다)

- **링크 경로에 괄호가 그대로 들어 있다.** 노션 파일 이름이 `…회원권 등)` 처럼 끝나서,
  `\(([^)]*)\)` 같은 정규식은 첫 `)` 에서 잘린다. 잘린 경로는 디스크에 없으므로 그 링크가
  통째로 사라지고, «문단 전체가 링크»라는 판정도 깨진다. 괄호 깊이를 세야 한다
  (`scanLinks`). 이 버그가 있는 채로 세면 하위 페이지 26건·인라인 20건이 덜 나온다.
- **폴더 이름에는 32hex id 가 없다.** 자식은 «id 를 뗀 제목» 폴더에 들어가므로
  `<폴더>.md` 를 찾으면 **한 건도 안 맞는다.** 부모는 폴더 이름 = 부모 제목으로 잇는다.
- **추출기가 200바이트 넘는 이름을 줄였다.** 본문 링크는 줄이기 전 이름을 가리키므로,
  조회할 때 같은 규칙으로 줄인 경로도 같이 봐야 한다(`shortenComponent`).

## 쓰기 경로를 붙일 때 (아직 안 했다)

- **실행은 라이브 배포 이후다.** 사용자가 정한 순서다.
- **이미지 업로드는 다른 업로드 화면과 같은 경로를 탄다.** `POST /files/upload/presign`
  → 스토리지 직접 PUT → `POST /files/upload/confirm`, 컨텍스트는 `archive-page-image`.
  업로드 전 **무손실 webp 변환**도 다른 경로와 같은 규칙으로 붙인다(무손실 고정,
  변환 결과가 원본보다 크면 원본을 그대로 올린다. GIF·SVG 는 손대지 않는다).
  admin-web 의 규칙은 `src/lib/utils/image-compress.ts` 에 있고, 노드에서는 sharp
  (`apps/admin-web` 에 0.34 가 설치돼 있다 — 0.35 는 쓰지 말 것)로 같은 결과를 낸다.
  요청 시 변환(#692)이 들어오면 이 자리는 원본 업로드만 남기면 된다.
- **`archive-page-image` 시드가 대상 DB 에 있어야 한다.** 라이브에 아직 없다 —
  배포와 `db:seed:ref` 가 짝이다. 빠지면 이미지 871개가 전멸한다.
- **정렬**은 파일명 순으로 `apps/core/src/modules/archive/sort-key.ts` 의 분수 인덱스를
  준다. `sort_key` 컬럼이 `COLLATE "C"` 인 것에 기댄다.
- **스페이스는 `team` 고정.** 루트 하나만 지정하면 서버가 부모를 따라 나머지를 정한다.
- **한 번에 루트 하나씩** 넣는다. 잘못되면 그 루트를 휴지통에 넣으면 하위가 따라간다.
- **마크다운 → 블록 변환을 라이브러리에 맡길 수 없다.** BlockNote 의 파서는 DOM
  (`prosemirror-model` 의 `DOMParser`)을 요구해 노드에서 안 돈다. 문단·제목·목록·인용·
  코드·이미지·링크만 직접 만든다. 완벽한 변환이 목표가 아니다.

## 아직 안 정한 것 (사람이 정해야 한다)

1. **비이미지 첨부 34개** (pdf 13 · mp4 4 · hwp 4 · xlsx 3 · ai 3 · docx/pptx/m4a 각 1 …)
   — `archive-page-image` 는 `image/*` 전용이라 그대로는 못 올린다. 제외할지, 첨부용
   컨텍스트(`archive-page-attachment` 등)를 새로 만들지.
2. **`.csv` 18개** (노션 DB/표 페이지, `_all.csv` 쌍 포함) — 표 블록으로 바꿀지, 첨부로
   둘지, 버릴지. 본문이 실제로 가리키는 건 1건뿐이고 나머지는 딸려 나온 export 다.
3. **`<aside>` 콜아웃 282개** — BlockNote 기본에 콜아웃 블록이 없다. 인용(quote)으로
   눕힐지, 커스텀 블록을 하나 더 만들지.
